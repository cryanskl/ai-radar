# Separate deterministic Search from bounded Ask

`Search` retrieves public AI Radar records without an LLM, while `Ask` synthesizes only from the public, versioned AI Radar dataset and must cite or abstain. A single general-purpose chat box would be easier to market, but would obscure retrieval cost, freshness and evidence boundaries and could turn the product into an uncontrolled web assistant rather than a trustworthy AI information system.
