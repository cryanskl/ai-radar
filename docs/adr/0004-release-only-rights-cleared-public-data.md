# Release only rights-cleared public data

The production database is not the open dataset: public pages, API responses and data releases consume `Public Records` produced through record-level rights and privacy decisions. Treating everything publicly reachable as redistributable would make bulk collection easier, but would incorrectly relicense third-party expression and expose internal or personal fields; code may be Apache-2.0 and AI Radar-owned data may be CC BY 4.0 without extending those licenses to every collected record.
